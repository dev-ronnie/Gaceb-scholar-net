# GACEB Scholar
A responsive Uganda curriculum learning platform for O-Level and A-Level students.

### Included
- Mobile-friendly homepage, course categories, About, contact, and real GACEB photos/logo
- Student signup/login via Supabase Auth
- Student profile and admin student table
- PDF uploads, moderation, signed downloads, and 5-coin award on approval
- Referral code support and admin verification flow for 5-coin rewards
- UGX 10,000 weekly / UGX 30,000 monthly premium presentation and donation button
- Gauge Assistant study-help demo
- SQL schema with row-level security

### Start here
Read `SETUP.md`. The homepage is plain HTML, CSS and JavaScript; no npm build is required. Live accounts, PDF storage and database tables require your own Supabase project. Real payment activation and live AI require secure server-side provider setup.
